# MYWONGO

> **새 주소로 옮겼습니다 (2026년 11월)**: 앱은 https://lightning-write.github.io/ , 내 라이트닝 페이지로 바로 가기는 https://lightning-write.github.io/lightning 입니다. 저장소도 [lightning-write/lightning-write.github.io](https://github.com/lightning-write/lightning-write.github.io)로 옮겼고, 이 저장소는 더 고치지 않습니다. 이 주소의 앱을 열면 아래쪽 띠에서 **새 주소로 옮기기**를 눌러 옮길 수 있습니다.

소설 원고용 편집기입니다. 인터넷이 없어도 열리고, 연결되면 구글 드라이브에 원고를 맞춰 둡니다.

- 코펍 바탕, 양쪽 정렬, 줄간격·들여쓰기 조절
- 글자 크기 슬라이더 하나: 글을 고르면 고른 부분만, 고르지 않으면 전체
- 메뉴를 접으면 전체 화면으로 종이만 남음 (Esc). 아래로 스크롤하면 펼치기 버튼이 숨음
- 장면 목록: 별표(＊)나 숫자만 있는 줄을 장면 구분으로 보고 목록을 만듦
- 휴지통(아이콘): 지운 원고는 30일간 보관 후 자동 삭제
- 맞춤법·띄어쓰기·오탈자 교정은 라이트닝 페이지의 **build**에서 합니다 (이 앱에는 없음)
- HWP·HWPX·TXT 불러오기(이 기기·구글 드라이브), 한글(.hwpx)·Word·TXT로 저장
- 원고는 먼저 기기에 저장되고, 드라이브에 연결해 두면 PC·휴대폰·태블릿이 서로 이어짐
- 라이트닝 페이지(claude.ai)와 오가기: **라이트닝**(번개 아이콘)으로 보내면서 페이지를 바로 열거나, **레이닝**(구름 아이콘)으로 보내기만 하고, 불러오기 → **라이트닝에서 받기**로 받음
- 스토밍 보기(곡선 아이콘): 라이트닝 페이지에서 세운 개요·인물·연표를 읽기 전용으로 봄
- 위치 띠: 스토밍한 원고 위에 '지금 여기' 단계와 분량상 위치를 보여 줌
- 아이콘에 마우스를 올리면 이름과 하는 일이 말풍선으로 뜸

**주소**: https://zax-zac.github.io/Wongo/ (저장소 이름의 대소문자 그대로 `Wongo`)

## 설정 안내

처음 한 번만 하면 됩니다. 이미 끝낸 단계는 건너뛰세요. 1단계가 끝나면 바로 쓸 수 있고, 2단계까지 마쳐야 드라이브 동기화가 켜집니다. 지금 이 저장소는 1·2단계가 모두 적용되어 있습니다.

### 1단계. 웹 주소 만들기 (GitHub Pages, 2분)

1. 이 저장소에서 **Settings → Pages**로 갑니다.
2. **Build and deployment**의 Source를 **Deploy from a branch**로 둡니다.
3. Branch를 **main**, 폴더를 **/(root)**로 고르고 **Save**를 누릅니다.
4. 1~2분 뒤 같은 화면 위쪽에 주소가 나타납니다. 주소는 `https://아이디.github.io/저장소이름/` 형태이고, 저장소 이름의 대소문자가 그대로 들어갑니다.

이 주소를 한 번 열면 그다음부터는 인터넷이 없어도 열립니다.

### 2단계. 구글 드라이브 연결용 클라이언트 ID 받기 (약 15분)

모든 화면은 [Google Cloud 콘솔](https://console.cloud.google.com/)에서 원고를 저장할 구글 계정으로 로그인한 상태에서 진행합니다. 비용은 들지 않고 결제 정보도 필요 없습니다.

1. **프로젝트 만들기**: [새 프로젝트](https://console.cloud.google.com/projectcreate)에서 이름을 `wongo`로 하고 **만들기**를 누릅니다. 만든 뒤 화면 위쪽 프로젝트 선택에서 `wongo`가 골라져 있는지 확인합니다.
2. **드라이브 기능 켜기**: [Google Drive API](https://console.cloud.google.com/apis/library/drive.googleapis.com) 화면에서 **사용**을 누릅니다.
3. **동의 화면 만들기**: [Google Auth Platform](https://console.cloud.google.com/auth/overview)에서 **시작하기**를 누르고 아래처럼 채웁니다.
   - 앱 이름: `MYWONGO`, 사용자 지원 이메일: 본인 메일
   - 대상: **외부(External)**
   - 연락처 정보: 본인 메일
   - 정책 동의 후 **만들기**를 누릅니다.
4. **본인을 테스트 사용자로 넣기**: [대상(Audience)](https://console.cloud.google.com/auth/audience) 화면의 **테스트 사용자**에서 **사용자 추가**를 누르고 본인 Gmail 주소를 넣은 뒤 저장합니다. '테스트' 상태 그대로 두면 됩니다.
   - 다른 사람도 이 앱을 자기 구글 계정으로 쓰게 하려면, 그 사람의 Gmail 주소를 여기 테스트 사용자에 더합니다(최대 100명). 아래 「다른 사람이 쓰려면」을 보세요.
5. **권한 범위 넣기**: [데이터 액세스](https://console.cloud.google.com/auth/scopes) 화면에서 **범위 추가 또는 삭제**를 누릅니다. 아래칸 '직접 범위 추가'에 `https://www.googleapis.com/auth/drive.file`을 붙여 넣고 **표에 추가 → 업데이트 → 저장**을 누릅니다.
   - 이 범위로는 앱이 직접 만든 파일만 볼 수 있습니다. 드라이브에 있는 다른 파일에는 손대지 못합니다.
5-1. **(드라이브 파일 열기용) 읽기 권한 추가**: 같은 화면에서 **범위 추가 또는 삭제**를 다시 눌러 `https://www.googleapis.com/auth/drive.readonly`도 같은 방법으로 추가합니다. 불러오기 → **구글 드라이브의 파일**에서 드라이브에 있는 HWP·HWPX·TXT를 고르려면 필요합니다.
   - 이 권한은 '고르기' 버튼을 누를 때만 따로 요청하고, 읽기만 합니다. 저장·동기화는 위의 `drive.file` 범위로만 합니다.
6. **클라이언트 만들기**: [클라이언트 만들기](https://console.cloud.google.com/auth/clients/create)에서 아래처럼 채우고 **만들기**를 누릅니다.
   - 애플리케이션 유형: **웹 애플리케이션**
   - 이름: `wongo-web`
   - **승인된 JavaScript 원본**에 `https://아이디.github.io`를 넣습니다. `/wongo`나 끝의 `/`는 붙이지 않습니다.
   - 승인된 리디렉션 URI는 비워 둡니다.
7. 화면에 나온 **클라이언트 ID**(`…apps.googleusercontent.com`으로 끝남)를 복사합니다.
   - 클라이언트 보안 비밀번호(secret)는 쓰지 않으니 어디에도 붙이지 마세요.
8. 클라이언트 ID를 이 저장소의 `config.js`에 넣습니다. 이 파일은 Claude가 대신 넣어 드릴 수도 있습니다.
   ```js
   window.WONGO_CONFIG = { googleClientId: '여기에-붙여넣기.apps.googleusercontent.com' };
   ```
   그리고 `sw.js` 맨 위의 `VERSION`을 하나 올립니다. 예: `wongo-v10` → `wongo-v11`.

이제 편집기를 열고 목록 아래 **드라이브 연결**을 누릅니다.
- 처음에는 "Google에서 확인하지 않은 앱"이라는 경고가 뜹니다. 본인이 만든 앱이므로 **계속**을 누르면 됩니다.
- 드라이브에 `MYWONGO` 폴더가 생기고, 그 안의 `동기화 자료 (지우지 마세요)` 폴더에 원고가 저장됩니다.

### 3단계. 휴대폰·태블릿에 앱으로 설치

- **아이폰·아이패드(Safari)**: 주소를 연 뒤 **공유 → 홈 화면에 추가**를 누릅니다.
- **안드로이드(Chrome)**: 주소를 연 뒤 **⋮ → 앱 설치** 또는 **홈 화면에 추가**를 누릅니다.
- **안드로이드(Edge)**: **≡ → 휴대폰에 추가**
- **PC(Chrome·Edge)**: 목록 아래 **앱으로 설치** 버튼을 누르거나, 주소창 오른쪽의 설치 아이콘을 누릅니다.

앱으로 설치해서 열면 처음부터 주소창이 없습니다. 브라우저 탭에서 열었을 때는 메뉴를 접으면 전체 화면이 되는데, 브라우저에 따라 지원 여부가 다릅니다. Chrome·Edge는 되고, DuckDuckGo 등 다른 브라우저는 안 될 수 있습니다. 그럴 땐 설치해서 쓰는 쪽이 확실합니다.

## 쓰면서 알아 둘 점

- **저장**: 입력을 멈추고 1초 안에 기기에 저장됩니다. 드라이브에 연결되어 있으면 몇 초 뒤 드라이브에도 올라갑니다. Ctrl+S를 누르면 바로 올립니다.
- **오프라인**: 인터넷이 없어도 열리고 써집니다. 다시 연결되면 자동으로 드라이브와 맞춥니다.
- **한 시간마다 다시 연결**: 구글 보안 정책상 드라이브 연결이 한 시간 뒤 만료됩니다. 목록 아래 **다시 연결**을 누르면 됩니다. 그사이 쓴 원고는 기기에 그대로 저장되어 있습니다.
- **두 기기에서 동시에 고친 경우**: 원고가 사라지지 않습니다. 다른 기기의 내용이 「제목 (다른 기기 사본)」으로 따로 남으니, 필요한 부분을 옮긴 뒤 사본을 지우면 됩니다.
- **휴지통**: 지운 원고는 휴지통(아이콘)으로 가고 30일 뒤 자동으로 지워집니다. 그 안에는 복원할 수 있습니다.
- **한글 파일**: **저장·내보내기 → 드라이브에 한글 파일 저장**을 누르면 드라이브 `MYWONGO` 폴더에 `제목.hwpx`가 만들어집니다. 다시 누르면 같은 파일이 새 내용으로 바뀝니다.
- **데이터가 지워지지 않게**: 브라우저의 '사이트 데이터 삭제'를 하면 기기에 저장된 원고도 지워집니다. 드라이브에 연결해 두거나, 가끔 **모든 원고 백업**을 받아 두세요.

## 라이트닝 페이지 (claude.ai)와 함께 쓰기

원고를 쓰고 다듬는 일은 claude.ai의 라이트닝 페이지에서 하고, 이 앱은 그 원고를 받아 보고 고치는 곳입니다. 라이트닝 페이지는 사람마다 자기 claude.ai 계정에 하나씩 만들어 씁니다. 만드는 법과 페이지 파일은 [`lightning/`](lightning/) 폴더에 있습니다.
원고는 구글 드라이브를 거쳐 오갑니다.

```
라이트닝 페이지 ──레이닝──▶ 드라이브 'MYWONGO/라이트닝 보낸 원고' ──라이트닝에서 받기──▶ 앱
앱 ──레이닝·라이트닝──▶ 드라이브 'MYWONGO/동기화 자료' ──(페이지를 열거나 돌아올 때 저절로)──▶ 라이트닝 페이지
```

**라이트닝 페이지의 메뉴** (아이콘에 마우스를 올리면 이름과 하는 일이 뜹니다)

| 이름 | 하는 일 |
|---|---|
| 번개 (오른쪽 아래) | 커서 자리에서 이어 씁니다. Ctrl+Enter, 엔터 두 번으로도 됩니다. 지운 제안은 '버린 방향'으로 기억합니다 |
| block / blocks | 번개 한 번에 나올 길이: 한두 문장 / 한 문단 |
| build | 쓴 데까지 맞춤법·띄어쓰기·군더더기를 정리합니다(원문 대비, 수락·거절) |
| bricks | 떠오른 소재를 모아 두는 조각함 |
| 스토밍 | 브레인스토밍으로 8페이지즈 개요를 짜고, 개요 완료로 인물표·연표를 만듭니다 |
| 레이닝 | 이 원고를 앱으로 보냅니다 |

**앱의 아이콘**
- **스토밍**(곡선): 라이트닝 페이지에서 세운 개요·인물·연표를 봅니다. 고치는 것은 라이트닝 페이지에서 합니다.
- **레이닝**(구름): 지금 원고를 바로 드라이브에 올리고 라이트닝 페이지로 보냅니다. 라이트닝 페이지는 그 원고를 열거나 그 페이지로 돌아올 때 이 판을 받아 이어서 작업합니다. 드라이브에 연결되어 있어야 합니다.
- **라이트닝**(번개): 누르는 순간 claude.ai의 내 라이트닝 페이지를 열고, 그동안 지금 원고를 레이닝 합니다. 라이트닝 페이지는 앱이 가장 최근에 보낸 원고를 알아보고 바로 엽니다(보던 원고는 목록에 남음). 이미 열린 라이트닝 창이 있으면 그 창을 씁니다. 처음 누를 때 내 라이트닝 페이지 주소를 넣으며, 주소는 기기마다 따로 저장됩니다(바꾸기: 원고 목록 아래 **라이트닝 주소**).
- **라이트닝에서 받기**(불러오기 메뉴): 라이트닝 페이지에서 레이닝 한 원고를 가져옵니다. 한 번 누르고 나면 한 시간 동안은 앱을 열거나 앱으로 돌아올 때 저절로 받습니다.
- **위치 띠**: 스토밍한 원고 위에 나타납니다. 남색 칸은 '지금 여기' 단계, 빨간 눈금은 커서까지의 분량이 목표 매수의 어디쯤인지입니다. 둘이 어긋나면 '분량으로는 ○ 자리'라고 알려 줍니다. 칸을 누르면 그 단계가 펼쳐집니다.

알아 둘 점
- 양쪽에서 같은 원고를 따로 고쳤다면 어느 쪽 글도 덮어쓰지 않습니다. 앱은 라이트닝 쪽 내용을 「… (라이트닝 사본)」으로 따로 남기고, 라이트닝 페이지는 앱 판을 받을지 묻습니다.
- 라이트닝 페이지에서 번개로 나온 문장에는 점선 밑줄이 있습니다. 앱에서 고쳐 쓰면 밑줄이 사라집니다. 한글·Word 파일로 내보낼 때는 밑줄이 나가지 않습니다.
- 스토밍 자료와 조각은 원고와 함께 드라이브로 오갑니다. 앱에서 그 원고를 고쳐도 지워지지 않습니다.
- 원고는 claude.ai 계정이 아니라 구글 드라이브에 있습니다. 다른 claude.ai 계정에 라이트닝 페이지를 만들어도 커넥터가 같은 구글 계정이면 같은 원고가 똑같이 보입니다. 보내기 전의 사본만 페이지마다(브라우저마다) 따로 있습니다.
- 라이트닝 페이지는 claude.ai의 Google Drive 커넥터를 씁니다. 커넥터는 앱이 쓰는 것과 같은 구글 계정으로 연결해야 합니다. 번개·스토밍·build는 페이지를 연 claude.ai 계정의 사용량을 씁니다.
- 드라이브의 '동기화 자료' 파일 이름 끝에는 원고 번호가 붙습니다(예: 「연필 공장 [mvu630zvxw7s].json」). 라이트닝 페이지가 어느 원고인지 알아보는 표시이니 지우지 마세요.

## 다른 사람이 쓰려면

자기 구글 계정과 claude.ai 계정이 있는 사람은 이 앱을 똑같이 쓸 수 있습니다. 원고는 각자의 구글 드라이브에, Claude 사용량은 각자의 claude.ai 계정에 따로 잡힙니다.

1. **앱 주인**: 그 사람의 Gmail 주소를 구글 클라우드의 테스트 사용자에 더합니다(위 설정 4번, 최대 100명).
2. **쓰는 사람**: 앱 주소(https://zax-zac.github.io/Wongo/)를 열고 드라이브를 자기 구글 계정으로 연결합니다. 원고는 그 사람 드라이브의 `MYWONGO` 폴더에 쌓입니다.
3. **쓰는 사람**: [`lightning/`](lightning/) 폴더의 안내대로 자기 claude.ai 계정에 라이트닝 페이지를 만들고, claude.ai의 Google Drive 커넥터를 같은 구글 계정으로 연결합니다.
4. **쓰는 사람**: 앱의 번개를 처음 누를 때 자기 라이트닝 페이지 주소를 넣습니다.

## 파일 구성

| 파일 | 하는 일 |
|---|---|
| `index.html` | 화면 |
| `app.js` | 편집, 기기 저장, 드라이브 동기화, 레이닝·라이트닝에서 받기, 말풍선 |
| `storm-view.js` | 스토밍 보기(읽기 전용), 위치 띠 |
| `hangul.js` | HWP·HWPX 읽기, HWPX 만들기 |
| `hwpx-template.js` | HWPX 뼈대 ([python-hwpx](https://github.com/airmang/python-hwpx)의 Skeleton.hwpx, Apache-2.0) |
| `config.js` | 구글 클라이언트 ID |
| `lightning/` | 라이트닝 페이지(claude.ai) 파일과 만드는 법 |
| `sw.js` | 오프라인 실행. 앱 파일을 고치면 `VERSION`을 올려야 기기에 새 버전이 들어감 |
| `KoPub_Batang_Light.ttf` | KoPub 바탕 Light (한국출판인회의 무료 서체, 원본 그대로 탑재) |
